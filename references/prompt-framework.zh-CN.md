# 连笔写意提示词框架

先观察空间关系，再决定线条怎样连续运行。默认目标是空间意向与结构动势；完整轮廓、准确层数、人物造型不作为必须保留的内容。

## 组装顺序

| 层次 | 写入内容 |
| --- | --- |
| 输入角色 | 内容图决定空间；连笔参考决定运笔；建筑参考只辅助结构表达 |
| 空间意向 | 约 2–4 组围合／开敞、悬挑／支撑、递进／汇聚、虚／实关系 |
| 连笔路径 | 哪些关系由同一条笔势带出，何处转向、回带、按深或提轻 |
| 抽象取舍 | 合并层次、放开轮廓和透视、删除构件与材质信息 |
| 配景符号 | 人物一笔或两笔，植被可略去，不复刻数量与姿态 |
| 成品检查 | 空间有依据、运笔连贯、配景极简、留白充分 |

观察后替换下方占位内容，不要把占位符直接交给生图工具。

## 完整提示词

将图 1 的效果图转译为一张更加抽象、连笔、写意的黑白空间意向手绘。图 1 仅提供空间与结构内容。图 2 仅提供连续运笔、回带、提按、粗细变化和自由概括的笔触语言，不复制其构图或具体圈线。[如提供图 3：它仅辅助说明少数线条如何暗示建筑结构，不复制其建筑形态、完整轮廓或多图排列。]

从图 1 中只保留这些空间意向：[写入约 2–4 组具体的围合与开敞、体量与空洞、层叠与汇聚、悬挑与支撑等关系。] 用几组连续笔势表达它们：[写明主要行笔方向、如何转折或回带、何处用白纸留出空洞。] 保留主要方向和结构逻辑，可以合并多个层次、压缩透视、放开比例及轮廓，不要求每一层、每一件构件都可被辨认。

像建筑师在思考空间时快速落笔，让一条线沿相邻空间关系游走、转向、回带、短暂交叠后收住。一笔可以暗示多条边界；线条可以越过次要细节、留下未闭合的空间，不逐个围成完整物体。直线关系用有力度的折转，曲线关系用流动弧势。运笔连接不等于把所有实体相连，不改造原建筑的关键围合、空洞和支撑关系。

使用少数富于变化的黑灰连笔：结构汇聚或转折处按深成短促黑色重音，行进和收笔时提轻成细线，局部出现干涩、回勾或自由越界。不要均匀双描、密集细线网、机械平行线、细碎修补或无依据的圈线。不追求清楚的完整透视图，不将每片楼板补齐顶面、底面、厚度和收边；不画栏杆、窗格、材质、反射、家具与铺地缝。

人物只作为尺度墨迹，每人一笔、最多两笔极小的短竖或斜点，不分圆头、身体、手脚，不画火柴人、服装轮廓、坐姿或完整剪影。只留必要的少量疏密节奏，不复刻人数和姿态。原图植物可以省略，或用一两次轻顿带过；不新增配景。

明亮白底占据大部分画面。以白纸表达光、空气、空洞和未画出的形体，少数重笔表达深度与结构压力。不铺连续灰调、不逐层排线、不画完整阴影、不填黑整个建筑，不给背景叠加旧纸或噪点。笔触内部允许轻微干笔颗粒。

输出一张、一个视向的独立黑白意向草图，保留图 1 的大致方向关系与横竖方向，线团松弛地组织在白纸内。整体首先传达空间的围合、流动、张力与结构走向，不必成为完整可辨的建筑插画。不拼接原图，不加标题、文字、图例、签名、水印、画框或额外视图。

## 根据实际偏差修订

- **仍像完整透视图**：取消完整轮廓和准确层数的要求，把构件清单改写为空间关系；合并相邻边界到同一笔势，不只增加“抽象”形容词。
- **线条碎、连不起来**：明确一条线从哪里进入、如何回带、在哪里提轻退出，减少频繁抬笔与局部描边；不强制全图用一笔画完。
- **人仍有头和四肢**：不再使用“人物速写”一类措辞，只要求一笔或两笔微小墨迹，删除独立圆头与肢体分叉。如果建筑笔势已合适，就局部替换这些小剪影为不分叉的短竖或斜点，保留其余画面，不为修人物重画整幅空间。
- **过于乱画**：保留主行笔方向与关键空洞，删除与空间无关的装饰圈线；不靠恢复窗格或材质找回辨识。
- **参考造型污染内容**：重申输入角色，点明原图的关键空间关系，并以原内容图重新生成。
